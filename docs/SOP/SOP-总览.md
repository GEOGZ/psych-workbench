## 2. 阶段定义速查表

| 阶段 | 名称 | 核心目标 | 关键输出物 | 平均周期 |
|------|------|----------|-----------|---------|
| **0** | 客户准入与商机评估 | 筛选合格客户，评估可行性 | 《客户准入评估报告》 | 1-3 天 |

## 3. 跨阶段通用原则

### 3.1 数据安全与合规（贯穿全程）
- **GDPR / 个保法**：所有客户数据收集需获得明确授权
- **数据加密**：传输 TLS 1.3+，存储 AES-256
- **访问控制**：最小权限原则，操作日志全留存
- **跨境传输**：涉及境外服务器需完成安全评估

### 3.2 质量检查点（每阶段出口）
每个阶段结束前必须通过质量检查，检查项包括：
- [ ] 文档完整性（必填字段无遗漏）
- [ ] 数据准确性（客户信息、金额、日期核对）
- [ ] 合规性审查（法务/合规团队签字）
- [ ] 客户确认（关键节点需客户书面/邮件确认）

### 3.3 异常处理机制
| 异常类型 | 处理原则 | 升级路径 |
|----------|----------|----------|
| 客户需求变更 | 变更需书面记录，评估影响后调整 | 项目经理 → 商务总监 |
| 交付延期 | 提前 48h 预警，制定补救方案 | 项目经理 → 交付总监 |
| 数据泄露风险 | 立即冻结，启动应急响应 | 安全负责人 → CEO |
| 客户投诉 | 24h 内响应，48h 内给出方案 | 客户经理 → 客户成功总监 |

## 4. RACI 矩阵总览

| 角色 / 阶段 | 0-准入 | 1-需求 | 2-合同 | 3-执行 | 4-报告 | 5-收尾 |
|------------|--------|--------|--------|--------|--------|--------|
| **商务经理 (BD)** | R/A | C | R | I | I | R/A |
| **项目经理 (PM)** | C | R/A | C | R/A | R | C |
| **测评顾问** | I | R | I | R | R/A | C |
| **法务/合规** | C | C | R/A | C | I | I |
| **技术团队** | I | C | I | R | R | I |
| **客户成功 (CSM)** | I | C | I | C | C | R/A |
| **客户** | C | C | A | C | A | A |

> **R** = 执行 (Responsible) | **A** = 负责 (Accountable) | **C** = 咨询 (Consulted) | **I** = 知情 (Informed)
