# 阶段0：客户准入与商机评估

> [← 返回全景SOP](../00-全景SOP.md)
>
> **阶段目标**：筛选合格客户，评估商机质量，决定是否投入资源进行商务跟进
> **平均周期**：1-3 个工作日
> **责任主体**：BD（商务拓展）

---

## 1. 触发条件

- 收到客户咨询（官网表单、400电话、邮件、转介绍）
- 主动市场拓展发现的潜在客户
- 老客户的新需求或新部门需求

---

## 2. 操作流程

### Step 1：客户信息初登（15 min）

**执行人**：BD / 销售助理
**工具**：CRM 系统

**操作内容**：
1. 在 CRM 中创建客户档案，录入基础信息：
   - 公司名称、行业、规模（员工数）
   - 联系人姓名、职位、联系方式
   - 客户来源渠道
   - 初步需求描述
2. 查重：确认是否为已有客户或关联公司
3. 分配客户等级（A/B/C/D）：
   - **A级**：明确需求 + 预算充足 + 决策链清晰
   - **B级**：有需求但预算/时间未确定
   - **C级**：潜在需求，需长期培育
   - **D级**：需求不匹配或暂无合作可能

**输出物**：CRM 客户档案（状态：初步接触）

---

### Step 2：需求预沟通（30-60 min）

**执行人**：BD
**形式**：电话 / 视频会议 / 面对面

**沟通清单**：
- [ ] 客户背景：行业特点、发展阶段、组织架构
- [ ] 测评目的：招聘筛选、晋升评估、团队诊断、培训需求？
- [ ] 目标人群：职级、人数、地域分布
- [ ] 时间要求：期望启动时间、交付 deadline
- [ ] 预算范围：是否有预算？预算区间？
- [ ] 历史经验：是否做过类似测评？供应商是谁？满意度？
- [ ] 决策流程：决策人是谁？还需哪些人参与？
- [ ] 特殊要求：白标定制、API对接、数据本地化？

**输出物**：《客户需求速记表》（CRM 备注或独立文档）

---

### Step 3：可行性评估（30 min）

**执行人**：BD + PM（复杂项目需测评顾问参与）

**评估维度**：

| 维度 | 评估内容 | 通过标准 |
|------|----------|----------|
| **需求匹配度** | 我们的测评工具能否满足？ | ≥ 70% 匹配 |
| **技术可行性** | 人数、并发、定制化是否可支撑？ | 技术团队确认可行 |
| **合规风险** | 行业是否敏感？数据要求是否特殊？ | 法务初审无红线 |
| **商业可行性** | 预算是否覆盖成本？利润率是否达标？ | 毛利率 ≥ 30% |
| **交付周期** | 客户期望时间是否可达成？ | 有资源可排期 |

**决策矩阵**：
- **绿灯（Go）**：全部维度通过 → 进入阶段 1
- **黄灯（条件通过）**：1-2 个维度需关注 → 制定风险应对后进入阶段 1
- **红灯（No-Go）**：≥ 2 个维度不通过 → 礼貌拒绝或转入长期培育

**输出物**：《客户准入评估报告》（含决策建议）

---

### Step 4：内部立项（15 min）

**执行人**：BD
**审批人**：商务总监（A级客户）/ BD 主管（B级及以下）

**操作内容**：
1. 在 CRM 中更新商机状态为「已立项」
2. 创建项目编号（格式：`PSY-YYYYMM-XXX`）
3. 指定项目经理（PM）
4. 发送内部通知邮件（BD → PM + 相关团队）

**输出物**：CRM 商机记录（状态：已立项）

---

## 3. 阶段出口检查清单

- [ ] CRM 客户档案完整（必填字段 100%）
- [ ] 《客户准入评估报告》已填写并审批
- [ ] 项目编号已分配
- [ ] PM 已指定并通知
- [ ] 决策记录清晰（Go / No-Go 理由）

---

## 4. 常见问题与应对

| 问题 | 应对策略 |
|------|----------|
| 客户不愿透露预算 | 提供 2-3 个价格区间方案，观察反应 |
| 需求模糊，只说"做个测评" | 用场景化提问引导（招聘？晋升？团队？） |
| 决策链不清晰 | 请求安排与决策人的会议，或提供决策流程图 |
| 预算明显不足 | 推荐标准化产品而非定制方案，或建议分期 |
| 与竞品深度绑定 | 了解不满意点，强调差异化优势 |
