# 阶段2：合同与合规签约

> [← 返回全景SOP](../00-全景SOP.md)
>
> **阶段目标**：完成商务谈判、合同起草与签署，确保合规要求到位
> **平均周期**：5-14 个工作日
> **责任主体**：商务经理 (BD) 主导，法务/合规审核，PM 配合技术条款

---

## 1. 触发条件

- 阶段 1 完成，客户已签字确认《需求确认书》和《测评方案》
- CRM 商机状态为「需求已确认」

---

## 2. 操作流程

### Step 1：商务报价（1-2 天）

**执行人**：BD
**审核人**：商务总监

#### 1.1 成本核算

**核算维度**：

| 成本项 | 说明 | 计算方式 |
|--------|------|----------|
| **测评工具费** | 量表使用授权 | 按人次 × 单价 |
| **平台使用费** | SaaS 平台部署 | 按项目周期或固定年费 |
| **定制开发费** | 白标/API/特殊功能 | 按人天 × 单价 |
| **报告服务费** | 个人/群体报告生成 | 按报告数量 × 单价 |
| **解读服务费** | 专家一对一/团队解读 | 按小时/场次 |
| **项目管理费** | PM 全程服务 | 固定比例（通常 10-15%） |
| **差旅费** | 现场服务（如需） | 实报实销或包干 |

#### 1.2 报价策略

**定价模式选择**：

| 模式 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **按人次** | 人数明确，标准化测评 | 简单透明 | 人数变动影响收入 |
| **项目打包** | 定制化程度高 | 利润可控 | 需精确估算成本 |
| **年度订阅** | 长期合作，多次测评 | 现金流稳定 | 需持续服务投入 |
| **混合模式** | 基础订阅 + 增量人次 | 灵活平衡 | 报价复杂 |

#### 1.3 报价单编制

```markdown

## 项目编号：PSY-YYYYMM-XXX
## 客户名称：_________________
## 报价日期：_________________
## 报价有效期：30 天

| 序号 | 服务项 | 规格/说明 | 数量 | 单价 | 小计 |
|------|--------|-----------|------|------|------|
| 1 | 测评工具使用 | [量表名称] | ___ 人次 | ¥___ | ¥___ |
| 2 | 平台部署 | SaaS 标准版 | 1 套 | ¥___ | ¥___ |
| 3 | 白标定制 | LOGO+配色+域名 | 1 项 | ¥___ | ¥___ |
| 4 | 个人报告 | 标准版 PDF | ___ 份 | ¥___ | ¥___ |

|------|------|
```

**输出物**：《报价单》

### Step 2：商务谈判（1-3 天）

**执行人**：BD
**支持人**：商务总监（重大折扣或特殊条款）

#### 2.1 谈判准备

**资料准备**：
- [ ] 报价单及成本底稿
- [ ] 同行业案例（脱敏）
- [ ] 竞品价格情报（如有）
- [ ] 公司内部审批权限表

#### 2.2 常见谈判议题

| 议题 | 我方立场 | 让步空间 |
|------|----------|----------|
| **价格折扣** | 标准折扣 5-10% | 总监特批可达 15% |
| **付款账期** | 标准 30 天 | 可延长至 60 天（需审批）|
| **免费测试** | 标准 5% 备用 | 可增至 10% |
| **交付周期** | 按标准计划 | 加急需加收 20% |
| **知识产权** | 报告归客户，工具归我方 | 可协商源代码归属 |
| **违约责任** | 对等原则 | 上限为合同金额 20% |

#### 2.3 谈判记录

每次谈判后更新《谈判记录》：
- 日期、参与人、议题
- 客户诉求、我方回应
- 达成一致项、待确认项
- 下次行动

**输出物**：《谈判记录》、更新版《报价单》（如价格调整）

---

### Step 3：合同起草（1-2 天）

**执行人**：法务
**输入**：签字版《需求确认书》《测评方案》《报价单》

#### 3.1 合同结构

```
合同编号：PSY-YYYYMM-XXX-CT

第一章 合同主体
  1.1 甲方（客户）信息
  1.2 乙方（我方）信息

第二章 服务内容与范围
  2.1 服务明细（引用报价单附件）
  2.2 服务标准与验收标准
  2.3 服务变更程序

第三章 合同金额与付款
  3.1 合同总金额
  3.2 付款方式与时间节点
  3.3 发票类型与税率

第四章 双方权利义务
  4.1 甲方义务（配合提供资料、组织人员等）
  4.2 乙方义务（按时交付、保密、质量保证）

第五章 知识产权与数据
  5.1 测评工具知识产权归属
  5.2 测评数据所有权与使用权
  5.3 报告知识产权

第六章 保密条款
  6.1 保密信息范围
  6.2 保密期限（通常 3-5 年）
  6.3 保密例外情形

第七章 数据安全与合规
  7.1 数据保护措施
  7.2 个人信息处理合规
  7.3 数据跨境传输（如涉及）
  7.4 安全事件响应

第八章 违约责任
  8.1 延期交付责任
  8.2 质量不符责任
  8.3 付款逾期责任
  8.4 责任上限

第九章 不可抗力
  9.1 定义
  9.2 处理方式

第十章 争议解决
  10.1 协商优先
  10.2 仲裁/诉讼（通常约定我方所在地法院）

第十一章 合同生效与终止
  11.1 生效条件
  11.2 提前终止条件
  11.3 终止后数据处理

附件：
  附件一：《报价单》
  附件二：《需求确认书》
  附件三：《测评方案》
  附件四：《知情同意书》模板
  附件五：《数据安全协议》
```

#### 3.2 关键条款审核要点

| 条款 | 审核要点 | 风险等级 |
|------|----------|----------|
| **数据归属** | 明确原始数据归客户，分析模型归我方 | 🔴 高 |
| **知识产权** | 工具/算法不转让，仅授权使用 | 🔴 高 |
| **保密期限** | 不少于 3 年，离职后仍有效 | 🟡 中 |
| **责任上限** | 不超过合同金额，排除间接损失 | 🟡 中 |
| **争议管辖** | 优先我方所在地，或中立仲裁 | 🟡 中 |
| **自动续约** | 避免默认自动续约条款 | 🟡 中 |

**输出物**：《合同草案》v1.0

---

### Step 4：合规审查（1-2 天）

**执行人**：法务 + 合规专员

#### 4.1 法律合规检查清单

- [ ] 合同主体资质（营业执照、签约人授权）
- [ ] 个人信息处理合法性基础（同意/合同必要/法定义务）
- [ ] 数据跨境传输合规（如服务器在境外）
- [ ] 行业特殊监管要求（如金融、医疗、教育）
- [ ] 劳动法规合规（如测评用于招聘/晋升的公平性）

#### 4.2 数据安全审查

- [ ] 数据分类分级是否明确？
- [ ] 加密措施（传输/存储）是否约定？
- [ ] 访问控制机制是否合规？
- [ ] 数据保留期限和销毁程序是否明确？
- [ ] 安全事件通知时限（通常 72 小时内）？

#### 4.3 知情同意书审查


**输出物**：《合规审查意见》、《知情同意书》定稿

### Step 5：合同签署（1-3 天）

**执行人**：BD
**审批人**：商务总监（金额 > 50 万）/ 总经理（金额 > 100 万）

#### 5.1 内部审批流程

```
BD 提交 → 商务总监审核 → 法务审核 → 财务审核 → [总经理审批] → 盖章
```

#### 5.2 签署方式

| 方式 | 适用场景 | 操作要点 |
|------|----------|----------|
| **电子签** | 标准合同，时间紧迫 | 法大大/DocuSign，需实名认证 |
| **纸质签** | 重大合同，客户要求 | 双份原件，骑缝章 |
| **混合签** | 一方电子一方纸质 | 确认法律效力等同 |

#### 5.3 签署后操作

1. 合同扫描存档（PDF + 原件）
2. CRM 更新商机状态为「合同已签署」
3. 发送《项目启动通知》给客户
4. 财务开具预付款发票
5. PM 正式接手，启动阶段 3

**输出物**：签字盖章版《正式合同》、《项目启动通知》

## 4. 常见问题与应对

| 问题 | 应对策略 |
|------|----------|
| 客户法务修改核心条款 | 记录修改点，内部评估风险，协商替代方案 |
| 客户要求延长账期至 90 天 | 评估客户信用，可要求银行保函或分期降价 |
| 客户拒绝签署知情同意书 | 解释法律要求，提供简化版，必要时调整数据处理方式 |
| 合同金额超过审批权限 | 提前准备审批材料，走特批流程 |
| 客户要求我方承担无限责任 | 明确拒绝，提供行业标准责任上限条款 |
