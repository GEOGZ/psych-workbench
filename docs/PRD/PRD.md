## 1. 产品概述与愿景

### 1.1 产品定位

**心理测评全流程管理SaaS平台** —— 面向企业客户（B2B）的心理测评服务交付系统，覆盖从客户准入到项目收尾的完整业务生命周期。

### 1.2 产品愿景

> 成为企业心理测评服务领域最高效、最可靠、最智能的项目交付平台，让每一次测评服务都成为客户信任的基石。

### 1.3 核心目标

| 维度 | 目标 | 度量指标 |
|------|------|----------|
| **效率** | 缩短项目交付周期 | 平均交付周期 ≤ 14 天 |
| **质量** | 降低交付缺陷率 | 客户投诉率 ≤ 2% |
| **增长** | 提升客户续约率 | 年度续约率 ≥ 75% |
| **智能** | 自动化重复工作 | 人工操作减少 60% |

### 1.4 业务边界

```
┌─────────────────────────────────────────────────────────┐
│                    平台覆盖范围                           │
├─────────────────────────────────────────────────────────┤
│  ✅ 客户准入评估    ✅ 需求调研管理    ✅ 合同流程        │
│  ✅ 项目执行跟踪    ✅ 报告生成交付    ✅ 收尾与续约      │
│  ✅ 数据安全合规    ✅ 质量检查控制    ✅ 异常处理        │
├─────────────────────────────────────────────────────────┤
│  ❌ 心理测评量表设计（外部专业工具）                       │

│  ❌ 支付收款系统（集成第三方支付）                         │

```

## 2. 目标用户与价值主张

### 2.1 用户画像

#### 主要用户：企业HR/组织发展负责人

- **痛点**: 心理测评项目分散管理、进度不透明、报告质量参差不齐
- **需求**: 一站式项目管理、实时进度追踪、标准化报告输出
- **使用场景**: 季度员工测评、招聘测评、团队建设分析

#### 次要用户：项目经理（内部）

- **痛点**: 多项目并行管理困难、客户沟通成本高、交付标准不统一
- **需求**: 项目看板、自动化提醒、模板化交付
- **使用场景**: 同时管理5-10个客户项目

### 2.2 价值主张

**对客户**: 透明、高效、专业的心理测评服务交付体验  
**对内部团队**: 标准化、可追踪、可度量的项目管理能力  
**对管理层**: 全局可视的业务运营数据与决策支持

### 4.1 业务流程引擎

#### 4.1.1 六阶段状态机

```
                    ┌──────────────┐
                    │   潜在客户    │
                    └──────┬───────┘
                           │ 准入评估通过
                           ▼
                    ┌──────────────┐
         ┌─────────│   需求确认    │◄────────┐
         │         └──────┬───────┘         │
         │ 需求变更        │ 需求锁定        │
         │                ▼                 │
         │         ┌──────────────┐         │
         │         │   合同签约    │         │
         │         └──────┬───────┘         │
         │                │ 合同生效        │
         │                ▼                 │
         │         ┌──────────────┐         │
         └────────►│   项目执行    │◄────────┘
                   └──────┬───────┘
                          │ 执行完成
                          ▼
                   ┌──────────────┐
         ┌────────│   报告交付    │◄────────┐
         │        └──────┬───────┘         │
         │ 报告修订       │ 客户确认        │
         │               ▼                 │
         │        ┌──────────────┐         │
         └───────►│   项目收尾    │◄────────┘
                  └──────┬───────┘
                         │ 结项归档
                         ▼
                  ┌──────────────┐
                  │   已完成      │
                  └──────────────┘
```

#### 4.1.2 状态转换规则

| 当前状态 | 可转换至 | 触发条件 | 自动动作 |
|----------|----------|----------|----------|
| 潜在客户 | 需求确认 | 准入评分 ≥ 70分 | 创建项目档案 |
| 需求确认 | 合同签约 | 需求文档签署 | 生成合同草稿 |
| 需求确认 | 潜在客户 | 需求变更重大 | 回退并记录 |
| 合同签约 | 项目执行 | 合同双方签署 | 创建执行计划 |
| 合同签约 | 需求确认 | 合同谈判失败 | 回退并记录 |
| 项目执行 | 报告交付 | 测试数据收集完成 | 触发报告生成 |
| 项目执行 | 合同签约 | 客户要求变更 | 变更审批流程 |
| 报告交付 | 项目收尾 | 客户确认报告 | 触发结项流程 |
| 报告交付 | 项目执行 | 报告需重大修订 | 回退并记录 |
| 项目收尾 | 已完成 | 结项审批通过 | 归档并更新CRM |

#### 4.1.3 审批工作流引擎

```yaml
审批流程定义:
  合同审批:
    - 步骤1: 项目经理提交
    - 步骤2: 法务审核 (金额 > 10万)
    - 步骤3: 财务审核 (金额 > 5万)
    - 步骤4: 总监审批 (金额 > 20万)
    - 步骤5: 客户签署
    
  报告发布审批:
    - 步骤1: 测评专家审核
    - 步骤2: 项目经理确认
    - 步骤3: 客户确认 (可选)
    
  结项审批:
    - 步骤1: 项目经理提交结项报告
    - 步骤2: 财务确认收款
    - 步骤3: 业务管理员归档
```

#### 4.1.4 SLA监控与预警

| SLA类型 | 目标值 | 预警阈值 | 升级规则 |
|---------|--------|----------|----------|
| 需求响应 | 24小时内 | 18小时 | 超期自动通知总监 |
| 合同审批 | 3工作日 | 2工作日 | 超期每日提醒 |
| 项目启动 | 合同签署后2天 | 1天 | 超期升级至运营总监 |
| 报告交付 | 测试完成后5天 | 3天 | 超期通知客户并解释 |
| 问题响应 | 4工作小时 | 3小时 | 超期自动升级 |

### 4.2 客户管理模块

#### 4.2.1 客户档案

- 基础信息：企业名称、行业、规模、联系人
- 准入评估：评分卡结果、风险等级、历史合作
- 需求画像：测评目的、频次、偏好量表
- 合同历史：历次合同、金额、履约情况
- 沟通记录：会议纪要、邮件、电话记录

#### 4.2.2 准入评估评分卡

| 评估维度 | 权重 | 评分标准 |
|----------|------|----------|
| 企业规模 | 15% | 员工数、营收规模 |
| 行业匹配 | 20% | 与测评服务契合度 |
| 决策周期 | 15% | 历史决策效率 |
| 预算范围 | 20% | 项目预算充足度 |
| 合作历史 | 15% | 过往合作满意度 |
| 数据合规 | 15% | 数据安全合规能力 |

#### 4.3.1 项目看板

#### 4.3.2 项目详情页

- **概览**: 项目状态、进度条、关键里程碑、风险标识
- **时间线**: 阶段历史记录、状态变更日志
- **任务列表**: 可执行任务、负责人、截止日期
- **文档中心**: 合同、需求文档、报告、沟通记录
- **团队成员**: 项目角色分配、联系方式
- **客户视图**: 客户可见的进度与交付物

### 4.4 报告管理模块

#### 4.4.1 个人报告

- **报告模板**: 支持多种量表模板配置
- **数据导入**: 对接测评系统API或批量导入
- **自动生成**: 基于规则引擎自动生成报告内容
- **专家审核**: 测评专家审核与批注
- **客户交付**: 在线查看、PDF下载、邮件发送

#### 4.4.2 群体报告

- **数据聚合**: 多维度数据统计分析
- **可视化图表**: 柱状图、饼图、热力图、趋势图
- **对比分析**: 部门对比、时间对比、行业基准
- **洞察建议**: 基于数据的组织发展建议
- **导出格式**: PPT、PDF、Excel

### 4.5 合同与财务管理

#### 4.5.1 合同管理

- **模板库**: 标准合同模板、补充协议模板
- **审批流**: 多级审批、电子签集成
- **版本控制**: 合同变更历史、差异对比
- **到期提醒**: 合同到期前30/15/7天预警

#### 4.5.2 收款跟踪

- **付款计划**: 里程碑付款、分期付款配置
- **收款记录**: 实际收款、发票信息
- **逾期预警**: 逾期未收款自动提醒
- **财务对账**: 与财务系统数据同步

### 4.6 数据安全与合规

#### 4.6.1 数据分级

| 级别 | 数据类型 | 访问控制 | 加密要求 |

| L4-机密 | 原始测评数据 | 严格审批 | 全链路+密钥管理 |

| 故障恢复 | ≤ 30分钟 | RTO (恢复时间目标) |
| 数据丢失 | ≤ 5分钟 | RPO (恢复点目标) |
| 备份频率 | 每日 | 全量备份 + 实时增量 |

### 6.3 安全需求

| 需求 | 实现方式 |
|------|----------|
| 传输加密 | HTTPS/TLS 1.3 |
| 存储加密 | AES-256-GCM |
| 密码策略 | 最小8位，含大小写+数字+特殊字符 |
| 登录安全 | 失败5次锁定15分钟，支持2FA |
| 会话管理 | JWT Token，有效期8小时 |
| 审计日志 | 全操作记录，保留180天 |
| 数据脱敏 | 敏感字段展示脱敏 |

### 6.4 兼容性需求

| 平台 | 支持版本 |
|------|----------|
| 浏览器 | Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ |
| 移动端 | iOS 14+, Android 10+ |
| 分辨率 | 1920×1080 (推荐), 1366×768 (最低) |

### 6.5 可扩展性需求

- **水平扩展**: 支持多实例部署，负载均衡
- **微服务**: 核心模块可独立部署与扩展
- **多租户**: 支持未来SaaS多租户架构
- **插件化**: 报告模板、审批流程可插件化扩展
