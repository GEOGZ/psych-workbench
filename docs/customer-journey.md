## 2. 阶段一：认知 (Awareness)

### 2.1 阶段定义

**客户目标**: 了解心理测评服务，识别自身组织发展需求  
**业务目标**: 建立品牌认知，获取潜在客户线索  
**成功标准**: 官网访问量、活动参与数、线索转化率

### 2.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 搜索引擎 | 搜索"企业员工测评""心理测评服务" | 找到专业可靠的服务商 |
| 行业活动 | 参加HR峰会、组织发展论坛 | 了解行业趋势和最佳实践 |
| 社交媒体 | 浏览LinkedIn/微信公众号文章 | 获取有价值的专业内容 |
| 同行推荐 | 询问同行使用的测评服务 | 获得可信的口碑推荐 |
| 官网访问 | 浏览服务介绍、案例展示 | 快速了解服务能力和价值 |

### 2.3 客户情感

```
情感状态: 好奇 → 困惑 → 兴趣

😕 "市场上测评服务太多了，怎么选？"
🤔 "心理测评真的能帮我们解决组织问题吗？"
🙂 "这家看起来挺专业的，先了解一下"
```

### 2.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 信息过载，难以筛选 | 提供清晰的行业解决方案分类 | 官网行业专区 |
| 不了解测评价值 | 发布ROI计算器和案例数据 | 在线价值评估工具 |
| 担心数据安全 | 展示安全认证和合规资质 | 安全白皮书下载 |
| 缺乏同行参考 | 建立客户案例库（脱敏） | 案例中心 |

### 2.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| 官网月访问量 | ≥ 5,000 | Google Analytics |
| 内容下载量 | ≥ 200/月 | 表单提交统计 |
| 活动线索数 | ≥ 50/场 | CRM录入 |
| 线索→MQL转化率 | ≥ 15% | CRM漏斗分析 |

## 3. 阶段二：考虑 (Consideration)

### 3.1 阶段定义

**客户目标**: 评估不同服务商，确定最佳合作方案  
**业务目标**: 展示专业能力，赢得客户信任  
**成功标准**: 需求调研完成率、方案通过率

### 3.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 初次沟通 | 接听商务电话，回复邮件 | 快速响应，专业态度 |
| 需求调研 | 填写需求问卷，参加访谈 | 被充分理解，需求被重视 |
| 方案演示 | 观看产品演示，提问 | 看到解决实际问题的能力 |
| 案例参考 | 要求提供同行业案例 | 验证服务商的行业经验 |
| 试用体验 | 申请小规模试用 | 亲身体验产品易用性 |

### 3.3 客户情感

```
情感状态: 谨慎 → 信任 → 期待

😟 "他们能理解我们复杂的组织架构吗？"
🙂 "调研很细致，感觉被重视了"
😃 "方案很贴合我们的需求，期待合作"
```

### 3.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 需求表达不清 | 提供结构化需求调研模板 | 在线需求调研系统 |
| 担心实施风险 | 提供分阶段实施方案 | 项目计划可视化 |
| 预算不确定 | 提供透明定价计算器 | 在线报价工具 |
| 决策流程复杂 | 提供决策支持材料包 | 高管汇报PPT模板 |

### 3.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| 需求调研完成率 | ≥ 90% | 系统记录 |
| 方案通过率 | ≥ 70% | 商务反馈 |
| 方案→合同转化率 | ≥ 60% | CRM漏斗 |
| 平均调研周期 | ≤ 5天 | 系统记录 |

## 4. 阶段三：决策 (Decision)

### 4.1 阶段定义

**客户目标**: 完成采购决策，签署合作协议  
**业务目标**: 高效推进合同流程，降低签约阻力  
**成功标准**: 合同签署周期、签约成功率

### 4.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 合同审阅 | 法务/财务审核合同条款 | 条款清晰，风险可控 |
| 价格谈判 | 协商价格和付款条件 | 获得合理的价格优惠 |
| 内部审批 | 提交内部采购流程 | 流程顺畅，快速获批 |
| 电子签署 | 完成在线合同签署 | 签署便捷，合法有效 |
| 预付款 | 完成首付款支付 | 支付安全，发票及时 |

### 4.3 客户情感

```
情感状态: 紧张 → 安心 → 兴奋

😰 "合同条款会不会有隐藏风险？"
😌 "法务审核通过了，可以签约了"
🎉 "终于签约了，期待项目启动！"
```

### 4.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 合同审批周期长 | 提供标准合同模板加速审批 | 电子合同模板库 |
| 法务条款争议 | 提供法务FAQ和条款解释 | 合同条款注释 |
| 付款流程繁琐 | 支持多种付款方式 | 在线支付集成 |
| 签署流程复杂 | 电子签一键签署 | 电子签集成 |

### 4.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| 平均签约周期 | ≤ 10天 | 系统记录 |
| 合同审批通过率 | ≥ 85% | 商务反馈 |
| 电子签使用率 | ≥ 90% | 系统统计 |
| 首付款及时率 | ≥ 95% | 财务记录 |

## 5. 阶段四：使用 (Usage)

### 5.1 阶段定义

**客户目标**: 顺利完成测评项目，获得有价值的洞察报告  
**业务目标**: 高质量交付，超越客户期望  
**成功标准**: 项目按时交付率、报告满意度

### 5.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 项目启动 | 参加启动会，确认计划 | 团队专业，计划清晰 |
| 进度查看 | 登录平台查看项目进度 | 实时透明，随时掌握 |
| 问题沟通 | 提出疑问和变更需求 | 快速响应，有效解决 |
| 报告接收 | 查看和下载测评报告 | 报告专业，洞察深刻 |
| 报告解读 | 参加专家解读会议 | 理解数据，获得行动建议 |

### 5.3 客户情感

```
情感状态: 期待 → 满意 → 惊喜

🤞 "希望项目能按计划顺利进行"
😊 "进度很透明，沟通很顺畅"
🤩 "报告质量超出预期，数据洞察很有价值！"
```

### 5.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 进度不透明 | 实时项目看板 | 客户门户Dashboard |
| 沟通效率低 | 统一沟通记录 | 项目消息中心 |
| 报告难以理解 | 可视化图表+专家解读 | 交互式报告+预约解读 |
| 数据安全担忧 | 全程数据加密+合规认证 | 安全中心展示 |

### 5.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| 项目按时交付率 | ≥ 90% | 系统记录 |
| 客户满意度 (CSAT) | ≥ 4.5/5 | 交付后问卷 |
| 报告质量评分 | ≥ 4.5/5 | 客户反馈 |
| 问题响应时间 | ≤ 4小时 | 系统记录 |

## 6. 阶段五：续约 (Renewal)

### 6.1 阶段定义

**客户目标**: 评估合作价值，决定是否继续合作  
**业务目标**: 展示合作成果，推动续约升级  
**成功标准**: 续约率、续约金额增长率

### 6.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 结项评估 | 接收并评估结项报告 | 看到清晰的成果总结 |
| ROI回顾 | 评估测评带来的价值 | 量化价值，证明投入产出 |
| 续约提案 | 接收续约方案和报价 | 方案有吸引力，价格合理 |
| 服务对比 | 对比其他服务商 | 感受到独特价值和连续性 |
| 续约决策 | 内部讨论并决定 | 决策依据充分，风险低 |

### 6.3 客户情感

```
情感状态: 回顾 → 认可 → 期待

🤔 "这次合作到底给我们带来了什么价值？"
👍 "数据证明测评确实帮助了团队发展"
😃 "续约方案很有吸引力，期待下一轮合作"
```

### 6.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 价值感知不清 | 提供量化的价值报告 | ROI分析仪表盘 |
| 续约时机不当 | 智能续约时机推荐 | 续约预警系统 |
| 竞品诱惑 | 提供忠诚度优惠 | 续约专属折扣 |
| 服务疲劳 | 推出新功能/新服务 | 产品更新通知 |

### 6.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| 年度续约率 | ≥ 75% | CRM统计 |
| 续约金额增长率 | ≥ 20% | 财务记录 |
| 续约决策周期 | ≤ 30天 | 系统记录 |
| 流失预警准确率 | ≥ 80% | 模型预测 |

## 7. 阶段六：推荐 (Advocacy)

### 7.1 阶段定义

**客户目标**: 分享成功经验，获得推荐奖励  
**业务目标**: 获取高质量推荐线索，扩大口碑影响  
**成功标准**: NPS评分、推荐转化率

### 7.2 客户行为

| 触点 | 客户行为 | 期望 |
|------|----------|------|
| 满意度调研 | 填写NPS问卷 | 问卷简洁，尊重时间 |
| 案例授权 | 同意作为标杆案例 | 获得品牌曝光机会 |
| 主动推荐 | 向同行推荐服务 | 推荐奖励及时兑现 |
| 口碑传播 | 在社交媒体分享 | 获得感谢和认可 |
| 共创活动 | 参与产品共创 | 影响产品方向 |

### 7.3 客户情感

```
情感状态: 自豪 → 热心 → 忠诚

😊 "这次合作很成功，愿意分享经验"
🤝 "推荐给朋友，帮他们解决同样的问题"
🏆 "成为标杆客户，很有成就感"
```

### 7.4 痛点与机会

| 痛点 | 机会 | 平台支持 |
|------|------|----------|
| 推荐流程复杂 | 一键推荐，简化流程 | 推荐链接/二维码 |
| 奖励不透明 | 实时奖励追踪 | 推荐奖励仪表盘 |
| 缺乏推荐素材 | 提供推荐话术包 | 推荐工具包 |
| 案例曝光顾虑 | 提供匿名案例选项 | 脱敏案例授权 |

### 7.5 关键指标

| 指标 | 目标值 | 采集方式 |
|------|--------|----------|
| NPS净推荐值 | ≥ 50 | 问卷调研 |
| 推荐线索数 | ≥ 客户数的20% | CRM统计 |
| 推荐转化率 | ≥ 30% | 漏斗分析 |
| 标杆案例数 | ≥ 10个/年 | 运营记录 |
