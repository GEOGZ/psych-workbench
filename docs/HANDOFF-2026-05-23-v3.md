### 2.3 经营手册红线由谁守

| 条款 | 守护方 |
|---|---|
| §4.2 报告禁 AI 直接对客 | 人(v1 不做报告) |
| §4.3 不外包客户关系 | **代码守** — contractor 看不到客户联系/危机联系人/金额 |
| §5.3 不直接联系受测者 | 物理边界(v1 不存受测者数据) |
| §6.1 并发 ≤3 | 人(Dashboard 自警) |
| §6.2 50/30/20 收款 | 人(v1 不做应收) |
| §7.1 SLA | 人(v1 不做 SLA 监控) |
| §八 危机联系人必填 | **代码守** — `clients.crisisContact*` NOT NULL |
| 账户主权 | **代码守** — `role='owner'` 限 1 行,仅 owner 能任命/撤销 admin |

### 2.4 RBAC 四角色(本会话最后一轮调整)

| 角色 | 范围 | 备注 |
|---|---|---|
| **owner** | 全权 + 主权操作 | 1 个,主权操作:任命/撤销 admin、转让所有权、删账户 |
| **admin** | 全业务写,无主权操作 | N 个,同公司合伙人/员工,owner 邀请 |
| **contractor** | 仅被 grant 的项目,字段过滤 | 临时外包,有 `expiresAt` |
| **client_readonly** | magic-link,只读自家项目进度 | 无登录 |

### 2.5 技术栈关键调整

- 去 XState(8 状态用纯 TS enum + 事务函数)
- NextAuth v5 → v4 stable
- 去 Puppeteer + PDF-lib(报告 v1 不做)
- 删 `src/machines/` 目录

### 2.6 7 张表

`users / clients / projects / project_events / hat_logs / client_portal_tokens / contractor_grants`

- `users`:role enum 含 owner/admin/contractor、有 `invitedByUserId`
- `clients`:`crisisContactName/Phone` NOT NULL
- `project_events`:append-only 审计流水
- `hat_logs`:同 user 时间区间不重叠(exclusion constraint + 事务校验)
