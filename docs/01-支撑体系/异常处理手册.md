# 异常处理手册（Exception Handling Playbook）

> [← 返回全景SOP](../00-全景SOP.md)
>
> **用途**：标准化常见异常的处理流程，减少临场决策偏差
> **使用方式**：按异常类型索引，直接定位处理步骤

---

## 异常分类体系

| 等级 | 名称 | 定义 | 响应时效 | 升级路径 |
|------|------|------|----------|----------|
| P0 | 致命异常 | 项目无法继续，或存在法律/声誉风险 | 即时 | 立即升级至总经理 |
| P1 | 严重异常 | 重大进度/质量影响，需紧急干预 | 2小时内 | 升级至部门总监 |
| P2 | 一般异常 | 可现场解决，影响局部 | 当天 | PM 自主处理，日报同步 |
| P3 | 轻微异常 | 不影响主流程，可延后处理 | 次日 | 记录待办，周会跟进 |

---

## 按阶段索引

### 阶段0：客户准入 — 常见异常

#### 异常 0-A：客户拒绝提供预算信息

| 属性 | 内容 |
|------|------|
| **等级** | P2 |
| **触发** | 客户以"保密"或"还没定"为由拒绝透露预算 |
| **根因** | 客户不信任；客户确实未定；客户想先比价 |

**处理步骤**：
1. **换方式问**：不问具体数字，问预算区间（"大概在 5-10 万还是 10-30 万级别？"）
2. **给参考**：提供 2-3 个同规模客户的案例价格（脱敏）作为锚点
3. **设期限**："为了给您最匹配的推荐，能否在本周内给一个大致范围？"
4. **记录**：在 CRM 标注"预算待定，预计 X 日前确认"

**升级条件**：客户连续 2 次拒绝，且无法推进 → 升级至 BD 主管，评估是否继续投入

---

#### 异常 0-B：客户行业敏感（如军工、涉密单位）

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 客户所属行业涉及数据安全敏感领域 |
| **根因** | 合规风险高，可能需要特殊资质或本地化部署 |

**处理步骤**：
1. **暂停推进**：立即暂停商务流程，标记为"合规待评估"
2. **法务介入**：提交法务/合规团队进行风险评估（模板见附录）
3. **技术评估**：技术团队确认是否支持本地化/私有化部署
4. **决策**：
   - 可合规 → 继续，但合同增加特殊安全条款
   - 不可合规 → 礼貌拒绝，推荐合规替代方案（如客户自行采购工具）

**升级条件**：涉及国家秘密或法律法规明令禁止 → P0，立即上报总经理

### 阶段1：需求确认 — 常见异常

#### 异常 1-A：客户需求频繁变更

| 属性 | 内容 |
|------|------|
| **等级** | P2（3次内）/ P1（超过3次） |
| **触发** | 客户反复修改需求，导致方案无法定稿 |
| **根因** | 客户内部未对齐；客户期望"试试看"；客户缺乏决策力 |

**处理步骤**：
1. **冻结需求**：正式通知客户"当前版本为基线，后续变更走变更流程"
2. **内部对齐会**：邀请客户方所有相关方参与需求确认会，现场签字
3. **变更管理**：启用《需求变更申请单》，每次变更记录影响（时间/成本/范围）
4. **商业谈判**：超过 3 次重大变更，启动变更收费谈判

**升级条件**：客户拒绝走变更流程，或变更导致成本增加 > 20% → 升级至 BD 总监

---

#### 异常 1-B：客户期望与预算严重不匹配

| 属性 | 内容 |
|------|------|
| **等级** | P2 |
| **触发** | 客户想要"全套定制+现场驻场+实时报告"，预算只有 5 万 |
| **根因** | 客户不了解行业定价；客户测试我方底线；客户预算确实有限 |

**处理步骤**：
1. **教育市场**：提供行业定价参考，解释成本构成（工具授权+人工+技术）
2. **阶梯方案**：设计 3 档方案（基础/标准/高级），让客户自选
3. **价值聚焦**：帮助客户识别"必须有的"vs" nice to have"，优先保核心
4. **坦诚沟通**："以当前预算，我们能提供的是 X，如果要 Y，需要追加 Z"

**升级条件**：客户坚持不合理要求，且态度强硬 → 评估是否放弃，避免后续纠纷

---

### 阶段2：合同签约 — 常见异常

#### 异常 2-A：客户要求大幅降价（> 20%）

| 属性 | 内容 |
|------|------|
| **等级** | P2 |
| **触发** | 客户以"预算有限"或"竞品更便宜"为由要求降价 |
| **根因** | 客户采购习惯；竞品低价策略；客户真实预算不足 |

**处理步骤**：
1. **不直接降**：先强调差异化价值（工具信效度、服务深度、数据安全）
2. **换方案**：不降单价，调整服务范围（如减少解读场次、改用标准报告）
3. **有条件降**：承诺长期合作/提前付款/案例授权，换取折扣权限
4. **审批流程**：任何折扣 > 15% 需商务总监审批，> 25% 需总经理审批

**升级条件**：客户要求降价 > 30%，或威胁终止合作 → 升级至商务总监决策

---

#### 异常 2-B：客户法务对条款提出重大修改

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 客户要求修改责任上限、知识产权归属、争议解决地等核心条款 |
| **根因** | 客户法务保守；客户处于强势地位；行业惯例差异 |

**处理步骤**：
1. **分类评估**：
   - 可接受：付款条件、交付细节、 minor wording
   - 需谈判：责任上限、保密期限
   - 不可接受：知识产权转让、无限责任、单方解约权
2. **对等交换**：客户要求我方让步，需客户对等让步（如提前付款、延长合作期）
3. **法务对接**：双方法务直接沟通，减少信息传递失真
4. **决策升级**：不可接受条款的修改，需总经理审批

**升级条件**：客户坚持不可接受条款 → P0，评估是否放弃签约

---

### 阶段3：项目执行 — 常见异常

#### 异常 3-A：受测者参与率严重偏低（< 50%）

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 项目启动 1 周后，受测者完成率不足 50% |
| **根因** | 邀请方式不当；受测者抵触；时间冲突；技术障碍 |

**处理步骤**：
1. **诊断原因**：联系客户 HR，了解低参与率原因（问卷/访谈）
2. **客户施压**：请客户高层发催促邮件/开会强调重要性
3. **降低门槛**：延长截止日期、提供操作指导、安排集中测试时间
4. **调整样本**：如确实无法提升，与客户协商降低样本量或调整分析方式
5. **记录影响**：评估对统计效力的影响，在报告中披露

**升级条件**：参与率 < 30%，且客户不配合推动 → 升级至 PM 总监，评估项目继续价值

---

#### 异常 3-B：数据泄露或安全事件

| 属性 | 内容 |
|------|------|
| **等级** | P0 |
| **触发** | 受测者个人信息/测评结果出现在非授权渠道 |
| **根因** | 系统漏洞；人员失误；恶意攻击；第三方泄露 |

**处理步骤**：
1. **立即止损**：
   - 技术团队立即封堵漏洞，暂停相关系统访问
   - 删除/下架已泄露数据，联系平台删除（如社交媒体）
2. **评估影响**：
   - 泄露范围：多少人？什么数据？扩散程度？
   - 法律风险：是否触发《个人信息保护法》报告义务？
3. **通知相关方**：
   - 4 小时内通知总经理、法务、合规
   - 24 小时内通知受影响客户和受测者（按法律要求）
4. **补救措施**：
   - 提供信用监控服务（如适用）
   - 向监管部门报告（如法律要求）
   - 配合客户进行内部调查
5. **复盘改进**：
   - 72 小时内完成事件报告
   - 修订安全流程，防止再次发生

**升级条件**：无需升级，本身就是最高等级，总经理直接指挥

---

#### 异常 3-C：客户要求提前看数据或修改结果

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 客户以"好奇"或"想先准备"为由要求提前查看原始数据 |
| **根因** | 客户不信任流程；客户想操控结果；客户缺乏专业认知 |

**处理步骤**：
1. **明确拒绝**："按行业伦理和合同约定，原始数据在报告交付前不提供，以保证测评的客观性。"
2. **解释原因**：提前看数据可能导致霍桑效应（受测者知道被观察而改变行为），影响后续测评有效性
3. **提供替代**：可提供进度统计（如"已完成 80%"），但不提供个体或群体结果
4. **记录留痕**：客户的要求和回复记录在 CRM，防止后续争议

**升级条件**：客户坚持并威胁终止合作 → 升级至 PM 总监和 BD 共同决策

---

### 阶段4：报告交付 — 常见异常

#### 异常 4-A：客户对报告质量不满意

| 属性 | 内容 |
|------|------|
| **等级** | P2 |
| **触发** | 客户反馈"报告太浅""没有洞察""看不懂" |
| **根因** | 期望管理不足；报告确实质量欠佳；客户专业水平有限 |

**处理步骤**：
1. **澄清不满**：具体了解客户不满的维度（深度/呈现/建议/数据）
2. **分类处理**：
   - 合理不满：补充分析、增加可视化、重写建议部分
   - 期望过高：解释测评工具的局限性，提供额外服务（如工作坊）作为增值
   - 客户不懂：安排 1 对 1 解读，帮助客户理解报告
3. **限时修正**：承诺 3 个工作日内提供修订版
4. **预防复发**：复盘需求确认阶段，是否充分对齐了报告深度期望

**升级条件**：客户要求全额退款或威胁公开负面评价 → P1，升级至 CSM 总监

---

#### 异常 4-B：解读现场出现负面情绪（受测者崩溃/哭泣）

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 报告解读过程中，受测者因结果触发强烈负面情绪 |
| **根因** | 测评结果触及敏感点；受测者心理脆弱；解读方式不当 |

**处理步骤**：
1. **即时处理**：
   - 暂停解读，给予受测者空间和时间平复
   - 提供纸巾/水，保持陪伴但不逼迫继续
2. **评估状态**：
   - 判断是否需要专业心理干预（如自杀倾向、严重焦虑）
   - 必要时建议转介专业心理咨询（提供合作机构名单）
3. **后续跟进**：
   - 24 小时后联系受测者，确认状态
   - 如需要，安排免费的心理咨询服务（公司承担费用）
4. **记录与报告**：
   - 详细记录事件经过（保护隐私，匿名处理）
   - 向客户 HR 通报（不透露具体个人，只说"已妥善处理"）
5. **流程改进**：
   - 复盘解读方式，是否有措辞不当
   - 更新《解读伦理指南》，增加风险预警

**升级条件**：涉及自伤/自杀风险 → P0，立即联系专业危机干预机构

---

### 阶段5：项目收尾 — 常见异常

#### 异常 5-A：客户拖延付款/拒付尾款

| 属性 | 内容 |
|------|------|
| **等级** | P1 |
| **触发** | 合同约定的付款日已过，客户未支付尾款 |
| **根因** | 客户资金紧张；客户对交付不满；客户内部流程慢；恶意拖欠 |

**处理步骤**：
1. **友好提醒**：付款日前 3 天发送提醒，到期后第 1 天再次提醒
2. **了解原因**：直接联系客户财务或对接人，了解延迟原因
3. **分类处理**：
   - 内部流程慢：提供必要的付款资料协助，适当宽限
   - 对交付不满：启动质量复核，合理修正后重新请款
   - 资金紧张：协商分期付款或延期（需书面协议）
   - 恶意拖欠：发送正式催款函，启动法律程序
4. **财务协同**：财务部门跟进，必要时暂停该客户的新项目启动

**升级条件**：拖欠 > 60 天或金额 > 10 万 → 升级至财务总监和总经理

---

#### 异常 5-B：客户拒绝提供案例授权

| 属性 | 内容 |
|------|------|
| **等级** | P3 |
| **触发** | 项目结束后，客户拒绝签署《案例使用授权书》 |
| **根因** | 客户保密文化严格；客户担心竞品知晓；对服务不够满意 |

**处理步骤**：
1. **了解顾虑**：询问客户拒绝的具体原因
2. **提供保障**：
   - 承诺脱敏处理（隐藏公司名称、行业、规模）
   - 仅用于内部培训或匿名行业报告
   - 客户有权预审脱敏后的内容
3. **交换价值**：提供额外服务（如免费复测名额、行业对标报告）换取授权
4. **尊重决定**：如客户坚决拒绝，尊重客户意愿，不强行使用

**升级条件**：无，此为商业谈判，不涉及升级

## 跨阶段通用异常

#### 异常 G-A：关键人员离职/变动

| 属性 | 内容 |
|------|------|
| **等级** | P2 |
| **触发** | 客户方对接人、决策人或我方 PM/顾问离职 |
| **根因** | 正常人事变动；客户内部重组；我方人员流失 |

**处理步骤**：
1. **及时知悉**：建立"关键人员变动"通知机制，CRM 标记
2. **关系交接**：
   - 客户方变动：尽快与新对接人建立联系，重新介绍项目背景
   - 我方变动：安排经验丰富的接替者，与客户正式介绍
3. **知识转移**：确保新对接人掌握项目历史、客户偏好、未决事项
4. **关系维护**：变动后 2 周内安排一次面对面/视频沟通，巩固信任

---

#### 异常 G-B：客户投诉（电话/邮件/社交媒体）

| 属性 | 内容 |
|------|------|
| **等级** | P1（一般投诉）/ P0（公开负面/媒体） |
| **触发** | 客户表达不满，要求解释或赔偿 |
| **根因** | 服务失误；期望落差；沟通不畅；第三方挑拨 |

**处理步骤**：
1. **24 小时响应**：无论投诉渠道，24 小时内必须首次回应
2. **倾听记录**：让客户充分表达，详细记录投诉要点和客户诉求
3. **内部调查**：核实事实，区分"我方责任""双方责任""客户误解"
4. **提出方案**：
   - 我方责任：道歉 + 补救（重做/退款/补偿）+ 预防措施
   - 双方责任：解释 + 部分补偿 + 改进建议
   - 客户误解：耐心解释，提供证据，争取理解
5. **闭环确认**：客户确认满意后，书面确认投诉已解决
6. **复盘归档**：投诉记录归档，月度分析投诉趋势

**升级条件**：投诉涉及法律风险、媒体曝光、或客户为重要标杆客户 → P0
