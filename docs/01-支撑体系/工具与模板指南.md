## 二、系统工具清单

### 2.1 客户关系管理（CRM）

| 属性 | 内容 |
|------|------|
| **系统名称** | 待定（建议：HubSpot / Salesforce / 自建） |
| **核心用途** | 客户档案、商机跟踪、沟通记录、合同管理 |
| **关键字段** | 客户名称、行业、规模、决策链、预算、阶段、下一步行动 |
| **使用规范** | 每次客户沟通后 24h 内更新记录 |
| **权限设置** | BD 查看/编辑自己的客户；PM 查看/编辑自己的项目；总监查看全量 |

### 2.2 项目管理（PMO）

| 属性 | 内容 |
|------|------|
| **系统名称** | 待定（建议：Notion / Asana / 飞书项目 / 自建） |
| **核心用途** | 项目计划、任务分配、进度跟踪、文档协作 |
| **关键视图** | 甘特图（时间线）、看板（任务状态）、日历（里程碑） |
| **使用规范** | 项目启动后 48h 内建立项目空间；每周更新进度 |
| **权限设置** | 项目成员查看/编辑；跨项目需申请 |

### 2.3 测评平台

| 属性 | 内容 |
|------|------|
| **系统名称** | 待定（建议：自研平台 / 第三方如北森/TalentQ） |
| **核心用途** | 测评发放、数据回收、报告生成、结果分析 |
| **关键功能** | 多设备适配、防作弊、数据加密、API 对接 |
| **使用规范** | 项目执行前 3 天完成环境配置；测试链接需内部验证 |
| **权限设置** | 测评顾问配置工具；PM 查看进度；客户查看报告（按需） |

### 2.4 数据分析与报告

| 属性 | 内容 |
|------|------|
| **工具名称** | Python (pandas, matplotlib) / R / SPSS / Excel |
| **核心用途** | 数据清洗、统计分析、可视化、报告生成 |
| **关键规范** | 分析脚本版本控制（Git）；数据源脱敏处理 |
| **使用规范** | 原始数据不落地本地；分析结果需复核 |
| **权限设置** | 数据分析师操作；测评顾问查看结果；客户仅看最终报告 |

### 2.5 文档协作

| 属性 | 内容 |
|------|------|
| **系统名称** | 待定（建议：飞书文档 / Notion / Confluence） |
| **核心用途** | SOP 文档、项目文档、知识库、会议纪要 |
| **关键规范** | 文档命名统一格式：`[项目编号]-[文档类型]-[版本]` |
| **使用规范** | 重要文档需审批后发布；历史版本保留 |
| **权限设置** | 全员查看；编辑权限按项目/部门分配 |

### 2.6 财务与合同

| 属性 | 内容 |
|------|------|
| **系统名称** | 待定（建议：用友 / 金蝶 / 自建） |
| **核心用途** | 报价审批、合同台账、开票收款、成本核算 |
| **关键规范** | 合同编号规则：`PSY-YYYYMM-[客户简称]-XXX` |
| **使用规范** | 合同签署后 24h 内录入；收款后 48h 内更新 |
| **权限设置** | 财务全员操作；BD 查看自己的合同；总监查看全量 |

## 三、模板使用速查

### 场景：新客户首次接触

**需要模板**：
1. T-001 客户信息登记表 → 了解客户背景
2. T-002 客户准入评估报告 → 评估商机质量

**使用步骤**：
1. 收到客户咨询 → 发送 T-001 给客户填写（或电话代填）
2. 初步沟通后 → 填写 T-002，进行评分
3. 评分 ≥ 70 分 → 进入阶段1；评分 < 70 分 → 评估是否继续

---

### 场景：需求调研会议

**需要模板**：
1. T-003 需求调研问卷 → 会前发送客户预习
2. T-004 需求确认会议纪要 → 会后记录

**使用步骤**：
1. 会前 2 天 → 发送 T-003 给客户
2. 会议中 → 按 T-003 框架深入讨论，记录要点
3. 会后 24h → 完成 T-004，发送客户确认

---

### 场景：合同签署

**需要模板**：
1. T-006 报价单 → 商务谈判
2. T-007 商务合同 → 法务审核
3. T-008 保密协议 → 如有必要

**使用步骤**：
1. 方案确认后 → 基于 T-006 生成报价单
2. 价格谈判后 → 基于 T-007 起草合同
3. 涉及敏感信息 → 签署 T-008
4. 双方签字盖章 → 合同归档，录入财务系统

---

### 场景：项目启动

**需要模板**：
1. T-009 项目启动会议程 → 组织会议
2. T-010 项目计划书 → 规划时间线
3. T-011 受测者邀请邮件 → 发送邀请

**使用步骤**：
1. 合同签署后 3 天内 → 召开启动会，使用 T-009
2. 启动会后 → 发布 T-010，明确里程碑
3. 启动后 2 天内 → 发送 T-011，邀请受测者

---

### 场景：报告交付

**需要模板**：
1. T-013 个人报告模板 → 生成个人报告
2. T-014 群体报告模板 → 生成群体报告
3. T-015 报告解读指南 → 准备解读

**使用步骤**：
1. 数据回收完成 → 使用 T-013/T-014 生成报告
2. 报告 QA 通过 → 安排解读会议
3. 解读前 → 按 T-015 准备解读要点
4. 解读后 → 发送报告，客户确认接收

---

### 场景：项目收尾

**需要模板**：
1. T-016 结项报告 → 总结项目
2. T-017 客户满意度调研 → 收集反馈
3. T-018 案例授权书 → 申请案例授权
4. T-019 续约建议书 → 推动续约

**使用步骤**：
1. 报告交付后 1 周内 → 完成 T-016
2. 结项后 3 天内 → 发送 T-017
3. 客户满意 → 申请 T-018
4. 识别续约机会 → 准备 T-019

## 四、工具选型建议

### 当前阶段（初创/小规模）

| 场景 | 推荐工具 | 理由 |
|------|----------|------|
| CRM | 飞书多维表格 / HubSpot Free | 低成本，易上手 |
| PMO | 飞书项目 / Notion | 与文档打通，协作方便 |
| 测评平台 | 第三方合作 + 简单自研 | 快速启动，降低研发成本 |
| 文档协作 | 飞书文档 / Notion | 中文友好，权限灵活 |
| 财务 | Excel + 用友小型版 | 满足基础需求 |

### 成长阶段（中等规模）

| 场景 | 推荐工具 | 理由 |
|------|----------|------|
| CRM | Salesforce / HubSpot | 功能完善，可扩展 |
| PMO | Asana / Jira | 专业项目管理 |
| 测评平台 | 完全自研 | 形成核心壁垒 |
| 文档协作 | Confluence | 企业级知识管理 |
| 财务 | 用友/金蝶标准版 | 合规要求 |

### 成熟阶段（大规模）

| 场景 | 推荐工具 | 理由 |
|------|----------|------|
| CRM | Salesforce + 自研中台 | 高度定制 |
| PMO | 自研 PMO 平台 | 深度集成业务流程 |
| 测评平台 | 自研 + AI 增强 | 技术领先 |
| 文档协作 | 自研 + Confluence | 知识资产化 |
| 财务 | SAP / Oracle | 集团级财务管控 |

## 五、模板更新流程

```
发现问题/优化需求
    ↓
模板负责人起草修订版
    ↓
相关部门评审（法务/财务/业务）
    ↓
审批通过 → 更新版本号 → 发布通知
    ↓
旧版本标记"已废弃"，保留 90 天
    ↓
全员培训（重大变更时）
```

**更新频率**：
- 每季度回顾一次模板适用性
- 每次重大异常后检查是否需要更新
- 法律法规变化时立即更新
