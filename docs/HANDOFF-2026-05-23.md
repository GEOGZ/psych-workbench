## 四、建议的澄清问题清单(供新会话参考,不强制)

新会话可按这 8 个维度逐个发问(每条独立一轮):

1. **使用人数**:仅你一人 / 你 + 客户只读门户 / 你 + 偶尔外包人员临时账号?
2. **部署形态**:Vercel 公有云 / 自托管 NAS / 本地 PC 跑(单机)?
3. **客户访问入口**:不需要 / 只看自己项目进度 / 还能下载报告?
4. **受测者答题入口**:也在这个工作台 / 用第三方测评工具(问卷星/SurveyMonkey)只导入数据?
5. **MVP 优先模块**(多选):线索CRM / 阈值化报价合同 / 项目执行看板 / 报告生成器 / 应收账款 / 月度复盘?
6. **数据保密级别**:本地加密即可 / 需要审计日志 / 需要符合等保/PIPL 自评?
7. **报告模板形式**:固定模板填空 / 模板 + LLM 段落 / 完全由你手写?
8. **现金流自动化深度**:仅看板提醒 / 自动生成催款邮件草稿 / 接对公账户 API 自动对账?
