# 心理咨询工作台 — 操作手册

**系统地址**：https://psych-workbench.vercel.app  
**最后更新**：2026-05-30（v1.7 — 域名架构 + 官网返回链接）

---

## 1. 系统概览

本系统是一套面向心理咨询顾问团队的项目管理工具，覆盖从客户开发到项目收尾的全生命周期。

### 域名与入口

| 地址 | 用途 |
|------|------|
| `www.wisepsy.cn` | WisePsy 官方主站（品牌与对外展示） |
| `app.wisepsy.cn`（或当前 Vercel 域名） | 运营系统 / 工作台（本手册描述的系统） |
| `app.wisepsy.cn/portal/[token]` | 客户门户（无需登录，token 鉴权） |

> 运营系统登录页底部有"返回 wisepsy.cn 官网"链接；工作台顶部品牌名点击可跳回官网。

### 角色权限

| 角色 | 中文名 | 权限范围 |
|------|--------|----------|
| owner | 所有者 | 全部操作，含用户管理 |
| admin | 管理员 | 客户、项目、协作者管理 |
| contractor | 协作者 | 仅查看被授权项目的基本信息 |

> **红线**：协作者永远无法看到客户的紧急联系人姓名/电话、完整联系电话、备注。这是系统强制隔离，不可绕过。

## 2. 登录

系统支持两种登录方式，访问 `/login` 页面后通过 Tab 切换。

### 方式一：密码登录（主要方式）

1. 输入**邮箱**和**密码**，点击**登录**
2. 登录成功后自动跳转至工作台
3. 若账号未设置密码，系统提示错误，请改用魔法链接登录

**首次登录 / 被重置密码后**：系统自动跳转至**修改密码页**，须设置新密码后方可继续使用。

### 方式二：魔法链接（无密码登录）

1. 点击"**魔法链接**"Tab
2. 输入邮箱，点击**发送登录链接**
3. 收到邮件后点击链接，直接登录进入工作台，无需输入密码

> 魔法链接有效期 10 分钟，过期后需重新发送。

### 忘记密码 / 重置密码

1. 在密码登录页点击**忘记密码？**
2. 输入账号邮箱，点击**发送重置邮件**
3. 系统将发送一封带登录链接的邮件，点击链接后直接进入**设置新密码**页面
4. 设置新密码后自动跳转工作台

### 密码规则

密码须同时满足：
- 至少 8 个字符
- 包含大写字母（A–Z）
- 包含小写字母（a–z）
- 包含数字（0–9）
- 包含特殊字符（如 `!@#$%` 等）

## 3. 用户管理

路径：**工作台 → 用户管理**（仅所有者可见）

### 邀请用户

1. 在"邀请 / 预设用户"表单中填写**姓名**（必填）、邮箱和角色
2. 点击**确认**
3. 系统预置该账号；用户首次通过魔法链接登录后生效

### 修改用户姓名

在用户列表中，点击用户**姓名**（带虚线下划线），直接进入内联编辑模式：
- 修改后按 **Enter** 或点击 **✓** 保存
- 按 **Escape** 或点击 **✕** 取消

### 修改角色

在用户列表右侧的下拉菜单中直接选择新角色，立即生效。

### 查看上次登录时间

用户列表中"上次登录"列显示该账号最近一次登录的日期。未曾登录的账号显示"—"。

### 删除用户

点击**删除**后需二次确认。删除操作不可撤销。

### 设置用户密码（仅所有者）

为用户初次配置密码，或在用户遗忘密码时手动重设：

1. 在用户列表中点击**设置密码**按钮
2. 输入新密码（须符合密码规则）
3. 点击 **✓** 确认

密码设置后用户即可通过密码登录。

### 重置密码（仅所有者）

强制用户在下次登录时修改密码：

1. 在用户列表中点击**重置密码**
2. 二次确认后，该账号被标记为"必须改密码"
3. 用户下次登录后系统自动跳转至修改密码页，完成修改后恢复正常访问

## 4. 客户管理

路径：**工作台 → 客户列表**

### 新建客户

点击右上角"+ 新建"，填写：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 公司名称 | 客户机构全称 | 必填 |
| 联系人 | 对接负责人姓名 | 必填 |
| 联系邮箱 | 对接邮箱 | 选填 |
| 联系电话 | 对接电话 | 选填 |
| 紧急联系人 | 紧急联系人姓名 | **必填** |
| 紧急联系电话 | 紧急联系人电话 | **必填** |
| 备注 | 内部注记 | 选填 |

### 搜索客户

列表页顶部搜索框支持按**客户名称**或**联系人姓名**模糊搜索。

### 编辑客户

进入客户详情页，点击**编辑**按钮，修改后保存。

### 删除客户

- 若客户存在**任何项目记录**（含已完成），系统拒绝删除，以保留历史数据
- 仅无项目的新客户可被删除

## 5. 项目管理

路径：**工作台 → 项目列表** 或从客户详情页创建

### 新建项目

在客户详情页点击"+ 新建项目"，填写项目名称和备注。

### 项目状态

| 状态 | 说明 |
|------|------|
| 线索 | 初步接触，评估可行性 |
| 资格确认 | 需求调研，方案设计 |
| 需求挖掘 | 报价确认，合同签署 |
| 合同 | 项目启动，系统配置 |
| 执行 | 报告生成与交付 |
| 汇报 | 尾款结算，项目复盘 |
| 收尾 | 收尾处理中 |
| 完成 | 全部结束，归档 |

### 推进项目状态

在项目详情页底部点击**推进状态**按钮，按流程逐步推进。状态只能向前，不可回退。

### 编辑项目

点击**编辑**可修改项目名称和备注，其他字段由系统管理。

### 删除项目

仅**线索**阶段的项目可被删除。一旦进入资格确认阶段，项目将永久保留。

---

## 6. 阶段任务清单

每个阶段都有对应的任务清单，在项目详情页的"阶段清单"卡片中勾选。

### 线索阶段
- 客户基本信息已完整录入
- 初步沟通已完成（30-60 分钟）
- 可行性评估矩阵已填写
- Go/No-Go 决策已记录

### 资格确认阶段
- 需求调研已完成（业务/技术/合规三维度）
- 需求确认书已起草
- 测评方案已设计完成
- 客户已书面确认方案

### 需求挖掘阶段
- 报价单已发送并获客户确认
- 合同金额已确定
- 合规清单已完成（个保法/数据安全）
- 合同已正式签署

### 合同阶段
- 项目启动会已完成
- 系统配置已完成并测试通过
- 参与者邀请已完成（交付率 ≥ 95%）
- 数据质量检查已通过

### 执行阶段
- 个人报告已生成并审核
- 群体报告已生成并审核
- 报告已交付客户
- 客户已签署交付确认书

### 汇报阶段
- 尾款已收取
- 满意度调查已完成（NPS 已计算）
- 项目复盘会已完成
- 结项文档已归档

## 7. 协作者授权

协作者需要授权才能查看特定项目。

### 授权步骤

1. 进入项目详情页，找到**协作者**卡片
2. 从下拉菜单选择协作者，设置**到期日**
3. 点击**授权**

### 撤销授权

在协作者列表中点击**撤销**，立即生效。

> 授权到期后协作者自动失去访问权限，无需手动撤销。

---

## 8. 客户门户

客户门户是一个无需登录的只读页面，供客户查看项目进展。

### 颁发 Token

1. 进入客户详情页，找到**客户门户 Token** 卡片
2. 设置到期日（默认 30 天后）
3. 点击**颁发 Token**
4. 点击**复制链接**，将链接发送给客户

### 客户可看到的内容

- 项目阶段进度（6 个阶段的步骤条）
- 当前阶段任务清单完成情况
- 顾问备注（项目备注字段）
- 最近更新时间
- **项目报告**（仅顾问标记为"门户可见"的报告）

### 客户看不到的内容

- 紧急联系人信息
- 完整联系电话
- 内部备注（客户档案备注）
- 其他客户的任何信息

### 撤销 Token

在 Token 列表中点击**撤销**，客户链接立即失效。

## 9. 项目报告

顾问可将外部生成的 PDF/Word 报告上传至平台，并控制是否对客户门户可见。

### 上传报告

路径：**工作台 → 项目详情页 → 项目报告**卡片

1. 填写**报告标题**（如"综合素质测评报告"）
2. 选择**文件类型**（PDF / Word / 其他）
3. 选择本地文件（支持 `.pdf`、`.doc`、`.docx`）
4. 点击**上传报告**

上传成功后报告出现在列表中，默认**门户可见**。

### 门户可见控制

每条报告右侧有"门户可见"复选框：
- **勾选**：客户通过门户链接可看到并下载该报告
- **取消勾选**：仅内部顾问可见，客户门户隐藏

### 下载报告

点击报告行右侧的**下载**按钮，浏览器将打开带时效的签名链接（有效期 1 小时）。

> 下载链接 1 小时后失效，再次点击可重新生成。

### 删除报告

点击**删除**即从平台和云存储中永久移除，操作不可撤销。

### 客户门户下载

客户在门户页的"项目报告"区域点击**下载**按钮，系统记录下载日志（时间、Token）后生成签名链接，自动在新标签页打开。

> 每次客户下载均记录访问日志，可在内部审计时追溯。

## 10. 安全红线

以下信息受系统强制保护，协作者在任何情况下均无法访问：

| 受保护字段 | 原因 |
|------------|------|
| 紧急联系人姓名 | 客户隐私，仅内部负责人掌握 |
| 紧急联系电话 | 同上 |
| 客户完整联系电话 | 防止外部人员直接联系客户 |
| 客户档案备注 | 可能含敏感商业信息 |

## 11. 常见问题

**Q: 忘记密码怎么办？**  
A: 切换到登录页的"魔法链接（备用）"Tab，输入邮箱发送登录链接。登录后请联系所有者在用户管理页重新设置密码。

**Q: 初次登录必须改密码吗？**  
A: 是。所有者通过"设置密码"功能为账号配置初始密码后，该账号首次登录会自动跳转至修改密码页，完成修改后方可正常使用。

**Q: 如何删除有项目的客户？**  
A: 无法删除。系统保留历史数据，有项目记录（含已完成）的客户不可删除。如需停用，可在备注中标注。

**Q: 协作者可以看到哪些信息？**  
A: 协作者只能看到被授权项目的名称、状态、阶段进度，以及客户的公司名称和联系人姓名。紧急联系人、电话、备注等敏感信息对协作者不可见。

**Q: 客户门户链接过期了怎么办？**  
A: 在客户详情页重新颁发一个新 Token，旧链接自动失效。

**Q: 如何查看项目的操作历史？**  
A: 项目详情页底部的**事件时间线**展示所有状态变更、清单操作、协作者授权等记录。

**Q: 多个顾问可以同时操作同一个项目吗？**  
A: 可以。管理员和所有者均可操作所有项目；协作者需要被单独授权。
